# UrbanNexus engineering rules

Build the smallest complete system that proves the central idea end to end.
All operational data in this repository is synthetic. Never imply municipal access.
Keep decisions numerical, deterministic, inspectable and human-approved.
Never bypass hard constraints or manufacture a feasible recommendation.
Run `python -m pytest` and `npm --prefix frontend run build` before claiming completion.
MATLAB/Simulink execution must be distinguished from the Python reference fallback.
Do not check in invented MATLAB results or a fake .slx archive.
Keep scripts cross-platform; no secrets or external actuators.
